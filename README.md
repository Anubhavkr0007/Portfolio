## 👨‍💻 About The Project

Welcome to my personal developer portfolio website.

This portfolio represents my journey as a **Java Backend Developer and Software Engineer**, showcasing my technical skills, projects, certifications, education, and development experience.

The website is designed with a modern **dark glassmorphism UI**, responsive layout, smooth animations, and an interactive developer-style terminal interface.
